# Security policy

Please do not report security vulnerabilities in a public issue.

Contact the repository owner privately with:

- a clear description of the issue;
- the affected page, role or API;
- steps to reproduce it using test data; and
- the possible impact.

Do not access, download or modify live member data while investigating a
security issue.

Production database access, deployment credentials and administrator accounts
are not provided to ordinary collaborators. Rotate any credential immediately
if it is accidentally exposed.
