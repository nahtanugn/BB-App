Getting started

Choose the guide that matches what you are trying to do.

Officer or Member joining an existing company

  1. Ask the company administrator for the BB App web address and your account details.
  2. Choose “Connect an existing company” and enter the address once.
  3. Sign in with your own email and temporary password.
  4. Change the temporary password and complete the onboarding checklist.
  5. Open Help & tutorials from the signed-in app whenever you need role-specific guidance.

Administrator creating a new company

  1. Return to the welcome screen and choose “Set up a new company.”
  2. Follow the six-step administrator guide to create the Cloudflare app and private database.
  3. Create the first administrator, apply company branding and then create user accounts.
  4. Share the company app address with Officers and Members; never share the private setup code.

Administrator setup guide

Follow these steps once for your company. Cloudflare will create an empty, private BB App and a unique web address—no records are copied from another company.

  1. Prepare the company accounts

    Use accounts controlled by the company, not a member’s temporary personal account.

    • A verified Cloudflare account.
    • A GitHub account or organisation to own the app source.
    • The email address of the first administrator.
    • A private setup code containing at least 16 characters.

  2. Deploy the company app

    Open the guided Cloudflare installer, sign in and allow it to create a company copy of BB App.

    Open Cloudflare setup

  3. Complete the deployment settings

    • Choose a unique Worker name using letters, numbers and hyphens.
    • Keep the D1 database binding named DB.
    • Set ADMIN_EMAIL to the first administrator’s exact email.
    • Set SETUP_TOKEN to the private setup code prepared earlier.
    • Start deployment and wait for the build to finish successfully.

  4. Connect this desktop app

    Copy the new workers.dev address shown by Cloudflare, then return here and enter it.

  5. Create the first administrator

    On the new app, choose first-time setup. Enter the authorised email and the same private setup code, then create a strong administrator password.

  6. Finish company setup

    Complete onboarding, set the company name and logo under App branding, then create Officer and Member accounts. Share the company app address with users so they can choose “Connect an existing company.”

Administrator setup only. Never share the setup code or administrator password with ordinary users, and never commit them to GitHub.
